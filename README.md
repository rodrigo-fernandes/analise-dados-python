# Titanic Data Analysis Dashboard

Um dashboard interativo desenvolvido em **Python** e **Streamlit** para explorar o histórico de passageiros do Titanic. Esta aplicação permite visualizar correlações entre sobrevivência, classe social e gênero através de filtros dinâmicos.

## 📊 Funcionalidades
- **Filtros em Tempo Real:** Explore os dados filtrando por Sexo e Classe (1ª, 2ª e 3ª).
- **Visão Geral dos Dados:** Tabela interativa com os dados brutos filtrados.
- **Gráficos Estatísticos:** - Taxa de sobrevivência por Gênero.
    - Taxa de sobrevivência por Classe.
    - Comparação cruzada (Gênero + Classe).
- **Insights Dinâmicos:** Texto explicativo gerado automaticamente com base nos dados selecionados.

## 🛠️ Tecnologias
- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/) (Interface Web)
- [Pandas](https://pandas.pydata.org/) (Processamento de Dados)
- [Seaborn](https://seaborn.pydata.org/) & [Matplotlib](https://matplotlib.org/) (Visualização)
